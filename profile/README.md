# Flapbase

**The no-code platform for goal-directed AI agents.**

Flapbase lets teams deploy autonomous agents that understand business goals, operate on structured data, and work across your existing tools — without writing code.

Built on [Open Business Protocol](https://openbusinessprotocol.org).

---

## What Flapbase Does

- **Agents that understand goals** — not just tasks. Agents resolve intent from workspace context outward.
- **Virtual Database (VDB)** — a structured, agent-native data layer using the `_v.*` namespace vocabulary
- **No-code workflow builder** — compose multi-step agent workflows visually
- **MCP-native** — integrates with any MCP-compatible tool or data source
- **Data sovereignty** — your data stays in your workspace; full export/import portability

---

## Core Repositories

| Repo | Description |
|------|-------------|
| `flapbase-sdk` | TypeScript SDK for building OBP-compatible agents |
| `flapbase-mcp-server` | MCP server exposing VDB and agent capabilities |
| `flapbase-workflow-engine` | Agent workflow execution engine (BSL 1.1) |
